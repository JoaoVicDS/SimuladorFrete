# 🚚 Simulador de Frete

### 💡 Sobre o projeto

O **Simulador de Frete** é uma aplicação web desenvolvida com **HTML, CSS e JavaScript puro**, criada para realizar simulações de valores de fretes para transporte de produtos.

A simulação é baseada nos quilômetros rodados entre o endereço de origem e o de destino, utilizando o serviço **Google Maps Distance Matrix API** para calcular automaticamente a distância.

---

### 🌐 Visualização online

Acesse: [https://joaovicds.github.io/SimuladorFrete/](https://joaovicds.github.io/SimuladorFrete/)

---

### Funcionalidades
- Cálculo automático de distância entre origem e destino
- Simulação do valor do frete com base na distância
- Interface simples e fácil de usar
- Totalmente client-side (sem back-end)

---

### 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript  
- Google Maps DistanceMatrixService

### 🚀 Como rodar localmente

**Clone o repositório**

```
git clone https://github.com/JoaoVicDS/SimuladorFrete.git
cd SimuladorFrete
```
**Abra o arquivo index.html no navegador**
Você pode abrir clicando duas vezes no arquivo ou usar uma extensão como o **Live Server** no VS Code.
